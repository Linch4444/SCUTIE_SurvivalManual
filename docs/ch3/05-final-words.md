# 3.5 写在最后

## 给还没决定的你

如果你正在犹豫要不要转到工业工程，我只说一件事：

**这不是一个"更轻松"的选择。**

IE 的课程横跨管理、数学、仿真、经济，你需要学的东西比单一工科更多。它的好处不是省力，而是**给你更大的自由度**——你可以往数据走、往供应链走、往咨询走、往制造业走。

自由是有代价的，代价就是**你要自己选**。

## 给已经进来的你

你的同学们都是不安分于平庸的人，IE 的班级氛围一般都不错——你们是同路人。

**你究竟想好要怎么过了吗？**

如果决定了，那就去做吧。
