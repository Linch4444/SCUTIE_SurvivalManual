# 3.1 单晶管的自白

> **来路无可眷恋，穷途唯有向前。**

开始前，我想回顾一下我的大一大二时光：

如果把大脑比作电脑的处理器，有的人天生是集成电路，而我是一根单晶管。

我做不到在 2 小时的高强度计算里保证不出错。一场两个小时的考试，前半小时我是 5G，后一个半小时我是拨号上网——转圈，卡顿，掉线。我一度以为这是态度问题，后来发现这是物理问题。

我做不到像其他同学对基础学科有着那样的热爱，做不到天才们算大量矩阵运算完全不出错，也做不到对某一个专业领域有什么自己的见解与“意料之外情理之中的Shocking Idea”

**承认自己的极限，不是认输，是止损。**

我们所受过的应试教育，比如高考这张卷子，回答不了"你是什么样的人"。它只能回答"你在那个六月的那两天，把六门课的内容能回忆起多少"。前者是终身课题，后者是一次性的记忆检索。用后者去定义前者，就像用体检报告里的一项指标去定义你的人生——

> 或许合理，但一定很蠢。

所以这本手册想做的事情很简单：我们这些在华南理工工业工程 SCUT IE 先走一步的人，把踩过的坑、走过的捷径、以及那些“要是早知道就好了”的事，尽量诚实地说出来。

它可能有用，可能没用；可能让你会心一笑，也可能让你皱起眉头。我们都接受。

**唯一的目标：大学是人生中试错成本最低的一段时间。**

出了校门，试错的成本要用房租、KPI、职场口碑来支付。在校内，试错的成本可能只是一个学期的绩点、一次失败的小组作业、一段不长的尴尬。这个差价，就是大学送给你最贵的礼物。
