# 1.4 学科难度 ≠ 产业发展

我们从小被教的是：做的题越难，考的分越高。

这个逻辑顺延到大学，就变成了一个想当然的推论：

> **我学的知识越难，我毕业拿的薪资就越高。**

**不是这样的。**

你想，什么样的行业，知识会特别复杂？

必然是**已经高度发展过、前人把该踩的坑都踩完了**的行业。它才会有那么多沉淀下来的知识、方法、定理、模型。

反过来看那些看起来"没什么门槛"的新行业——直播、跨境电商、几年前的算法岗——恰恰因为还没有现成的教科书，先入场的人才有议价权。

所以规律是这样的：

> 一门学科的知识越复杂，越有那种让你拍案叫绝的证明，说明它发展越久、产业越老越成熟，就越难给出高薪。

为什么？因为前人已经证明了某种模式就是最好用的，各种复杂情况都考虑到了。你要做的只是**把结论调包过来用**，不需要你创造什么。

反过来说：

> 一门学科的学习资料越少，说明它越前沿。很多知识还停留在论文里，没有沉淀进教科书。它给出的溢价就越高。

## 这条规律对 IE 意味着什么？

IE 的课程体系横跨运筹学、统计学、管理学、经济学——这些都是**非常成熟、沉淀极深**的学科。线性规划的最优解理论发展了几十年，你今天在课本上学到的，是无数前人智慧的结晶。

好处是：**你不必从零开始发明，工具都是现成的。**

代价是：**光靠"会用这些成熟工具"，很难拿到高溢价。**

那溢价在哪里？

在**那些还没有沉淀进教科书的领域**——数据分析做了几年就开始换代的工具链、AI 落地的具体场景、你的行业 know-how 和判断力。

**所以结论不是"别学运筹学"，而是：**

- 课本知识要学扎实（这是你的地基）
- 但别指望课本知识直接变现
- 真正的溢价，来自**把成熟工具用在还没有标准答案的新问题上**

这也就是 IE 的尴尬和机会所在——它教你的是一套成熟的分析框架，而你要做的，是用这套框架去解那些**框架还没覆盖到的问题**。

> 你不需要发明微积分，但你需要知道，微积分解不了的那个问题，该用什么。
