# 1.5 自我：以终为始

史蒂芬·柯维说的"以终为始"，翻译成大学生能听懂的话就是：

**先想清楚四年后你想站在哪里，再倒推今天该干什么。**

大部分人做选择的方式是"别人都在考，我也考"、"这个看起来比较稳"。结果就是四年后站在毕业季的岔路口，手里握着三个都不太想要的选项。

正确的做法是反过来：

## 第一步：定终点

你想要的是哪一种生活？

| 方向 | 关键词 | 代价 |
|---|---|---|
| 升学（考研/保研） | 学历提升、延缓就业、换赛道 | 一年高压备考，机会成本高 |
| 就业 | 早入场、攒经验、拿现金 | 起点学历可能受限 |
| 考公 / 选调 | 稳定、体制内、地域绑定 | 竞争激烈、收入天花板明确 |

注意：**这三条路不是互斥的，但不能同时全力准备。** 你必须在某个时间点做出取舍。

> 求稳 OR 求变，这是大学本科一定要想清楚的问题

## 第二步：查信息

选方向之前，先把信息补齐。第二章会展开讲，这里只列清单：

- **升学**：考研考什么专业、报录比多少、专业课考哪几门；保研比例、绩点线、加分项
- **就业**：目标行业头部公司在招什么人、要求什么技能、什么时间开秋招/春招
- **体制内**：广东省人社厅、国家人社部、定向选调的政策文件原文（不是营销号解读）

## 第三步：倒排时间线

举个粗糙的例子：

```
目标：大四秋招进制造业/互联网做供应链或数据分析
├─ 大三上：运筹学、管理统计学拿到高绩点（专业课是硬通货）
├─ 大三下：找一个暑期实习（哪怕是中小公司，先有经历）
├─ 大三暑假：正式暑期实习，争取转正或拿到背书
├─ 大四上：秋招，投递 30+ 家
└─ 贯穿全程：学 SQL / Python / 数据分析工具，这是 IE 的通用货币
```

有了这张表，你每天该干什么就清晰了。**焦虑的反面不是躺平，是具体的行动。**

## 四年时间线：大一到大四

上面那张表讲的是**方法**——从终点往回推。下面这张表讲的是**落地**——从你现在的位置往前看。

两件事别搞混：倒排是"我要去哪儿、所以现在做什么"；时间线是"我现在这个阶段，最该做的几件事是什么"。

### 大一：先想清楚「要不要转」

- 别急着回答"我喜欢什么"，先回答一个更实在的问题：**我愿意为哪个选择负责？**
- 去听 IE 的宣讲、翻培养方案、找一两个 IE 的学长学姐聊聊天
- 基础课（数学、英语）打牢——不管转不转，这些都不亏
- 允许自己没想明白。**方向是撞出来的，不是想出来的**

### 大二：申请 + 打底

- 盯住二次选拔（2+2）的时间节点，**别错过报名**——错过要再等一年
- 深化专业知识，参加一个你真正感兴趣的竞赛
- 第一份实习可以开始尝试了，不挑公司大小，要的是"有经历"
- 这一年你手上的信息量会翻好几倍，方向感就是在这时候长出来的

### 大三：正式进入 IE

- 从原专业转过来，第一学期往往会有点吃力——知识面一下子宽了，需要重新搭框架
- 专业课拿高绩点是硬通货（运筹学、管理统计学）
- 实习是主线：暑期实习争取转正，或者至少拿到一段能写进简历的背书
- 到这一年末，升学还是就业，必须有个倾向了

### 大四：收口

- 升学：考研 / 保研 / 出国的申请节点都集中在这一年的上半年
- 就业：秋招提前准备，投递 30+ 家，别拖到春招
- 无论走哪条：把简历、作品、人脉收拾干净——这是四年积累的一次清算

**一句提醒**：这张表是参考，不是课表。每个人的节奏不一样，快一点慢一点都没关系。真正重要的是，你在每个阶段都**做了一次真实的选择**，而不是把选择权交给"别人都在做什么"。
