# 1.3 如何评价一所大学

> 所有大学都在宣传自己的排名、实验室、院士数量。
> 
> **但，这些东西跟你一个本科生，说实话，关系不大。**
> 
> 真正影响你这四年过得爽不爽、值不值的，是下面这5件事：

## 1. 氛围是否自由、是否单一唯 GPA 论

有的学校氛围宽松，允许你折腾副业、搞社团、逃一些没意义的课；有的专业疯狂考勤，早读点名、晚自习打卡、上课收手机，还有数不清的实验耗费你宝贵的青春，把你当成高三的延长版。

没有绝对的好坏——如果你是个需要外部约束才能学习的人，严格的管理反而是好事。但你要**知道自己在什么样的环境里**，而不是稀里糊涂被同化。

## 2. 技术类社团是否丰富

这是接触不同学科、不同人群最省力的渠道。在社团里，你遇到的可能是机械的、计算机的、设计的、材料的——这些人在未来会变成你的跨学科队友、创业伙伴、或者帮你内推的同事。

## 3. 有没有讨论股票、就业、行业的群聊

一个活跃的、讨论真实职业信息的群，价值超过十门导论课。它让你在大二就知道大四要面对什么。

## 4. 校友圈是否联系紧密

校友圈的密度，决定了你毕业十年后换个城市还能不能找到人一起吃顿饭。这是隐性的社会资本。

## 5. 实习机会是否丰富

城市（地段）这一条值得单独说。

> **华工最大的、被最严重低估的资产，就是它在广州。**
>
> 深圳一小时、东莞一小时、佛山半小时。你周围三小时车程内的制造业、物流业、互联网公司数量，超过国内绝大多数城市的总和。工业工程是一个高度依赖"现场"的学科，而你恰好站在全国最大的现场旁边。
