# 1.6 「华工很务实」这句话

进校之前，我经常听到别人评价华工，只有两个字：**务实**。

我当时很不理解。务实算什么评价？听起来像是"没有特色"的委婉说法。别的学校有"自由""浪漫""理想主义"，到我们这儿就两个字，"务实"。

后来我懂了。

务实不是一个宏大叙事，它是一件件小事。


是小组活动不搞虚头巴脑的计划组织，大家分好任务就各自干活；
是 IE 学长学姐愿意花两个小时给你讲他们踩的坑，而不是敷衍一句「加油！」；
是你提一个方案，没人问你「这符合理论吗」，而是说「先跑跑试试」。

**这一件件小事加起来，就是一个学校的精神。**

它是这个学校里师生的做事态度。

真正务实的人，反而最早承认自己的边界。

所以我们承认我们做不好，但这只是暂时的——我们永远相信着，我们能做、我们还会去改。

所谓：

**博学之、慎思之、笃行之**

不过是：

从来不审问魑魅魍魉，从来不明辨是是非非

我们只会一直在路上，学习着，思考着，行走着，直到最后一刻
