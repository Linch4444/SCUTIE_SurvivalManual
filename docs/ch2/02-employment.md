# 2.2 就业

## 基本情况

IE 的就业方向这些年有明显变化：

| 时期 | 主流去向 |
|---|---|
| 2020 年以前 | 互联网企业（运营、产品、数据、供应链） |
| 2020 年以后 | 新能源制造业（宁德时代、比亚迪、小鹏、广汽等） |

**一个好消息：你投岗位不会被筛简历。**

这是学长学姐的原话，含义是——IE 的"管理学学位 + 工科背景"组合，在简历筛选环节是比较通吃的。你能投互联网的运营/数据岗，也能投制造业的 IE/供应链/生产计划岗，还能投咨询、物流、零售。

**但要清醒一点**："不被筛简历"意味着"更容易进入下一轮竞争"，不意味着"更容易拿到 offer"。简历过了之后，比的是真本事。

## 学长学姐经历参考

从管院学长的分享材料里，可以看到 IE 出身做数据分析类岗位的实际路径：

```
滴滴出行（运营策略分析）
    ↓
携程（酒店定价）
    ↓
字节跳动（产品分析）
    ↓
腾讯（商业化分析）
```

**这条路径的核心能力，不是运筹学，而是"用数据回答业务问题"的能力。**

所以如果你想走这条路：

1. **运营岗 / 计划岗 起手**。不管第一份工作如何，自己学，积累行业内的经验，一步步转到产品经理 / 运营主管。
2. **Python 与统计学是加分项**。庄东老师的运筹学课会带你快速入门，别浪费。假设检验、AB 实验、因果推断——这些是数据分析岗的面试高频。
3. **Excel 是基本功**。别笑，真的。



## IE vs AI：会被替代吗

学长给的答案很清晰，两个方向：

### 1. 跨界设计：多领域融合

IE 融合经济、大数据基建、生物医药等多领域知识。比如智能交通系统，要同时懂交通工程、信息技术。AI 擅长单点落地，不擅长跨界的"缝合"（其实就是和同事扯皮）。


### 2. 人机指挥家：AI 与人类协作

IE 工程师的角色是"人机指挥家"——让 AI 处理数据，人类负责决策。

所以： **不会用 DS（数据科学）工具的数据分析师，不是好的数据分析师。**

打不过就加入。与其焦虑 AI 会不会取代你，不如想想怎么让 AI 成为你的实习生。
