# A.5-A.6 找数据与识破欺骗

## A.5 找数据

**宏观数据：**

- 国家统计局
- 国家数据（data.stats.gov.cn）
- 北大数据开放平台

**微观 / 商业数据：**

- 大数据导航（hao.199it.com）
- 参照系、天天投、投中网（行业公司列表）
- CB Insights（独角兽）

**付费专业数据：**
- Wind
- 彭博、路透、FT
> 如果你是因为完成计量论文来到这的，可以尝试在[学校图书馆-数据库资源](https://www.lib.scut.edu.cn/zwsjk_40859) 找到相应的付费数据库
推荐 CSMAR ，有完整的国内上市公司财务数据！

## A.6 数据欺骗：怎么识破

**六个必查项：**

1. **真实性 / 时效性**——数据是哪年的？
2. **是否隐瞒了信息**——省略规模只谈百分比？
3. **数据与结论是否对齐**——先自己从数据推结论，再对比作者结论
4. **平均值是什么**——平均数？中位数？众数？分布如何？
5. **测量误差**——怎么测的？
6. **图表是否被拉长压缩**——看刻度起点
