# D.2 华工《维特鲁威》

有风过夏，日月换新；

有凤栖梧，激醴而鸣。

翼展千里，梦归苍穹；

学子入园，意气风发。

又是一年，洋溢青春锐意的华园，迎来崭新的身影。

你也许正怀抱豪气，迫不及待渴望大显身手；

你也许正满怀欣喜，盼望梦想此时近在眼前；

你也许正审视自己，等待着破茧蜕变的那天……

当然，你也许正在疑惑着、不安着——全新的环境，或许也意味着陌生的一切：

宿舍生活该如何适应？智慧校园该如何使用？校际通勤该如何完成？

针对这数不尽的问号，SCUT 学生创新俱乐部为你带来解决的办法。

翻开这本[华工手册《维特鲁威》](https://scut.wiki)，它将给你答案。
