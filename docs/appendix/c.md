# A.3 学科知识地图

> 这张图帮你了解 IE 之外还有哪些学科门类，想学某个东西时知道从哪找，不必全部学一遍。

## 为什么要看这张图

课程之外还有很多你没接触过的领域。先知道它们研究什么、与自己学的东西有什么联系，以后遇到问题就多一个查找方向。

---

## 学科门类总览

```
01 哲学    02 经济学   03 法学    04 教育学
05 文学    06 历史学   07 理学    08 工学
09 农学    10 医学     11 军事学  12 管理学
13 艺术学
```

> 教育部标准门类。IE 的根，长在 **08 工学 + 12 管理学 + 02 经济学 + 07 理学** 的交叉处。


## 与 IE 直接相关的知识域
### ① 运筹与优化（07 理学·数学）

```
运筹学
├─ 线性规划 → 单纯形法 → 对偶理论
├─ 整数规划
├─ 非线性规划
├─ 动态规划
├─ 图论与网络流
├─ 排队论        ← 与系统仿真直接对接
├─ 库存论        ← 与库存管理、供应链对接
├─ 决策分析      ← 与预测与决策方法对接
└─ 博弈论        ← 与微观经济学、管理学对接
```

**关联课程**：运筹学、预测与决策方法、系统仿真

### ② 统计与数据（07 理学·统计）

```
概率统计
├─ 概率论（测度论基础）
├─ 数理统计
├─ 回归分析 / 多元统计
├─ 时间序列分析
├─ 随机过程      ← 排队论的理论基础
├─ 贝叶斯统计
├─ 因果推断      ★ 数据分析岗的核心壁垒
└─ 生存分析（医学生存分析）
```

**关联课程**：管理统计学、商业数据分析、大数据挖掘

::: tip 给 IE 的提醒
**因果推断** 是被严重低估的一块。AB 实验、政策评估、定价策略背后的方法论都在这里。
:::

### ③ 计算与工具（08 工学·计算机）

```
计算机
├─ 编程语言（C / C++ / Python / Java）
├─ 数据结构与算法
├─ 操作系统
├─ 计算机网络
├─ 数据库原理      ← IE 必修
├─ 机器学习
│   ├─ 有监督学习
│   ├─ 无监督学习
│   └─ 强化学习
└─ 数字图像处理
```

**关联课程**：数据库、管理信息系统、大数据挖掘

> 对 IE 来说，**不需要学到 408 的深度**。但 `SQL + Python + 一门统计工具` 是通用货币。

### ④ 管理与运营（12 管理学）

```
管理
├─ 工商管理
│   ├─ 会计 / 财管 / 税法 / 审计
│   ├─ 战略管理
│   ├─ 人力资源管理
│   └─ 市场营销
├─ 管理科学与工程   ★ IE 的学科归属所在
├─ 公共管理（行政、医疗、教育、社保）
└─ 情报学（信息检索）
```

**关联课程**：管理学原理、生产计划与控制、质量管理、供应链管理、物流管理、库存管理

### ⑤ 经济与金融（02 经济学）

```
经济学
├─ 理论
│   ├─ 微观：供需、博弈论、国富论
│   ├─ 宏观：国际金融、货币银行学、财政学
│   └─ 计量经济学
└─ 应用
    ├─ 投资学、公司理财
    ├─ 估值模型（DCF）
    └─ 行业研究（投研、IPO）
```

**关联课程**：微观经济学、技术经济学

|---|---|

| **07 理学·系统科学** | 《系统之美》——系统思维，与 IE 同源 |
| **03 法学** | 专利产权法（你做创新要用）、经济法 |
| **04 教育学** | 如果你做家教、做培训 |
| **10 医学** | 只有做医疗相关 IE 才涉及 |
| **13 艺术** | 做产品、做设计时的审美底子 |

## 怎么用这张图

**不建议**：从上到下把每一块都学一遍。你会死在第二块。

**建议**：

1. **先锚定一个方向**（比如"数据分析"）
2. **沿着这一条线深入**（统计 → 因果推断 → 机器学习 → 业务落地）
3. **旁边的领域，知道存在就行**，需要的时候再回来查

> 广度给你视野，深度给你饭碗。
> **先有深度，再扩广度。** 反过来的人，四年后什么都懂一点，什么都不精。
