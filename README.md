## 这是什么

仿《上海交大生存手册》体例编写的**开源经验手册**。按三章结构组织，外加一份工具型附录：

1. **认清现状** — 你站在哪里
2. **基本方向** — 你往哪走
3. **存在主义** — 你怎么活
4. **附录** — 怎么查、怎么判断、路有哪些（可以当字典用）

## 关键前提（读之前必须知道）

- 华工工业工程隶属**工商管理学院**，不是机械学院
- 学生大多在大二通过**二次选拔**从理工科院系转入，不是高考直招
- 学位是**管理学学士**
- 面向对象：在读的、准备转入的、以及还在犹豫的华工工工学生

## 怎么跑起来

需要 Node.js 20 或更高版本（推荐 22 LTS）。

```bash
# 安装依赖
npm install

# 本地预览，改完自动刷新（默认 http://localhost:5173）
npm run docs:dev

# 构建静态站点（输出到 docs/.vitepress/dist）
npm run docs:build

# 预览构建产物
npm run docs:preview
```

## 部署

**线上地址：https://linch4444.github.io/SCUTIE_SurvivalManual/**

仓库已配置 GitHub Actions 工作流，推送到 `main` 分支即自动构建并发布到 GitHub Pages（约 45 秒生效）。

**首次部署需要手动开启（本仓库已完成）：**

1. 在 GitHub 仓库的 Settings → Pages 里，Source 选择 **GitHub Actions**
2. 如果仓库名不是 `<用户名>.github.io`，需要把 `docs/.vitepress/config.mts` 里的 `base` 改成 `'/仓库名/'`
3. 推送后等待 Actions 跑完，站点即可访问

## 接力开发（给下一届的你和你的 AI 助手）

这个仓库沉淀了两届开发者的全部经验——写作铁律、加章节 SOP、构建部署流程、Windows/沙箱环境踩坑、多人协同规范——全在这两个文件里，**随仓库一起 clone**：

- **`.workbuddy/skills/scutie-manual/SKILL.md`** — AI agent 的接力技能（用 WorkBuddy / CodeBuddy 等工具打开本项目会自动加载）
- **`.workbuddy/skills/scutie-manual/references/ops-guide.md`** — 人类可读的运维指南

**接力约定：改完东西后，把新踩的坑、新的决策写回 SKILL.md 对应章节**。经验不写回去，下一届就要重新踩一遍。

### 写作约定

- **一节一页**：文件放在对应章节目录下，命名 `序号-英文短名.md`
- 每页开头必须有 `---` 包裹的 `title` 字段（只写小节名，**不要带编号**）
- **侧边栏自动生成**，不用手改配置：文件名前缀决定编号（`docs/ch2/03-internship.md` → 「2.3 实习」），`title` 决定显示文字。新增页面只要按规范命名放进目录，侧边栏自动出现
- 附录 `a.md`、`b.md`、`c.md` 合为「附录 A 工具与方法」三节；`d*`、`e*` 分别为附录 D、E，编号写在 `title` 里。保留原文件名与页面地址
- 风格参照现有内容：短句、直白、敢下判断，允许吐槽和网络语
- 引入新事实时，**页脚注明来源和日期**
- 两个铁律：**不编造**（没素材就留「待补充」）、**不发散**（严格按既定框架写）
